# مجتمعنا

منصة تواصل عربية بواجهة RTL، مبنية على Firebase وVercel Functions.

## الحالة

هذه النسخة تتضمن مصادقة Firebase Authentication، قواعد Realtime Database، ونقاط API خادمية للمكافآت ومكالمات الفيديو. الدفع الإعلاني لا يعلن نجاحه ولا يحفظ الإعلان قبل ربط بوابة دفع حقيقية.
